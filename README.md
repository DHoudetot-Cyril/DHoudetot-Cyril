### 🧑‍💻 En bref

- 🤖 Je construis des **applications LLM qui vont au-delà de la démo** : agents, RAG, mesures de qualité, traces et monitoring.
- 🏠 Tous mes projets IA tournent **100 % en local** (llama.cpp, vLLM, Ollama) sur un GPU AMD avec ROCm. Pas de clé d'API, pas de données qui sortent.
- 📏 J'aime **mesurer avant d'affirmer** : tests, jeux d'évaluation, benchmarks et décisions d'architecture écrites (ADR).
- 🐧 Côté infra : Docker, CI GitHub Actions, Ansible, Linux au quotidien.
